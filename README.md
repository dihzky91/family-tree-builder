# Silsilah Keluarga (`family-tree-builder`)

Aplikasi web untuk membangun, memvisualisasikan, dan mengelola silsilah keluarga.

## Teknologi yang Digunakan

- Vite
- TypeScript
- React
- shadcn-ui & Radix UI
- Tailwind CSS
- Supabase

## Menjalankan Secara Lokal

Pastikan Node.js dan npm sudah terpasang.

```sh
# Install dependencies
npm install

# Jalankan development server
npm run dev
```

## Skrip Lainnya

- `npm run build` — Build untuk produksi
- `npm run preview` — Pratinjau hasil build produksi
- `npm run lint` — Menjalankan ESLint
- `npm test` — Menjalankan unit test dengan Vitest
